# XRPL Interactive Learning Lab

An independent educational XRPL project with an interactive learning website and a Remotion-powered lending explainer video.

Educational only. Not affiliated with or endorsed by XRPL Foundation.

## Website
Open `index.html` directly in a browser or deploy the repository to GitHub Pages. All simulations are local and do not transmit transactions.

## Video
See `video/README.md` for Remotion setup, preview, and MP4 export.

## Accuracy
Lending specifications are evolving. XLS-66 is a draft as of Nov 2026; verify amendment activation at https://xrpl.org/resources/known-amendments before updating materials.

Sources: https://xls.xrpl.org/xls/XLS-0066-lending-protocol.html ; https://xrpl.org/ ; https://www.remotion.dev/docs/render
